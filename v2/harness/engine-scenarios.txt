# ======================================================================
# Part 2. Milestone 5 scenario extension. Every scenario logs the engine
# snapshot after each command (snapshots full: SNAP and SNAPX lines).
#
# The profiles reproduce what MainForm configures on the engine when the
# user picks a rate model or a gate (MainForm.ApplyRateChoice and
# SynchronizeRateProcessing): an ordinary rate model sets Simulate slowdown
# and one service model; a gate (Per-note interval, Delayed NoteOff, Note
# attack limit, Output rate limit) turns Simulate slowdown off and is
# selected as the Start processing mode. MainForm's own defaults
# (100 us processing time, 31,250 bit/s, 10,000 events/s) fill the unused
# service fields. Representative values are chosen to bite on the dense
# fixtures; they are not the product defaults.
# ======================================================================

profile rate-none
  set simulate-slowdown off
  service processing-time 100 31250 10000
end-profile
