Analysis examines the MIDI source without sending it to an output. It graphs source workload and, for ordinary rate models, projects queue pressure, overflow, and output completion. With a note or output gate selected, it instead projects the gate's selected MIDI messages at their logical times. Output rate gate is an ideal nonblocking projection; live provider blocking can change later decisions. When Output-paced timeline is on, ordinary slowdown projection pauses source progression during deterministic simulated service, but it cannot predict third-party provider blocking.

The first workload preview may appear before the slower queue projection is ready. Analysis does not predict driver or synthesizer delay or live channel mutes. This window's default-off Project forced overrides command snapshots the current forced values, applies them after Track routing, and reports generated forced messages separately from filtered competing source messages. It affects only this Analysis window and never sends MIDI or changes Playback.

Drag the divider, zoom the graph, or click to inspect a time. Seek to pin can move the player to the selected point. This Analysis window's title-bar menu can show integer event counts per accepted graph interval instead of events/sec; the switch redraws the current result without recalculating it.
