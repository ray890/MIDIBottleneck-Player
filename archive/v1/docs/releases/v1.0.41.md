# Build 41 — Offline, focus-aware Help

Original handoff date: 2026-09-25 EDT

## Player changes

- Press **F1** in the main window or choose **Help (F1)…** from its title-bar menu to open a built-in guide. It begins at the topic for the focused control and also lets you choose File/output, Rate model, Queue, Playback, Analysis, Statistics, or Channels yourself.
- The Help window stays usable alongside playback and is reused when you ask for help again. It does not reset the player or need an internet connection, separate help file, or special question-mark title bar.

## Project and documentation changes

- Added the offline guidance to the user and technical guides. The main window's existing layout and playback controls are unchanged.

## Verification

- Focused WinForms tests cover the F1 key-preprocessing route, native menu command, focused-topic choice, useful content, window reuse/closing, handle recreation, icon, and working-area fit. Full x86/x64 totals and release hashes are in the private checkpoint.

## Known limitations

- Context selection covers the main window. Analysis and Channels retain their existing control tooltips and the linked public user guide; their own F1 routing is not added in this build.
