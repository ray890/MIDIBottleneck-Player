# Build 40 — Discoverable Rate models

Original handoff date: 2026-09-25 EDT

## Player changes

- Rate model now offers **None**, three simulated slowdown choices, and the **Per-note interval gate** in one visible dropdown. Group labels cannot be selected. None is selected on a fresh launch and remembers the last-used values of the other models.
- The separate slowdown checkbox and Per-note system-menu command are gone. The optional finite forward-only queue remains available and is labelled **Forward-only queue admission** when active, so it is not mistaken for delayed playback.
- Live ordinary rate switches still keep playback and sounding state. Changes to or from None or Per-note gating use the established safe transition. The gate's note-selection rules and the queue's overflow rules are unchanged.

## Project and documentation changes

- Updated the user and technical guides for the visible model selector and its relationship to forward-only queue limiting.

## Verification

- Focused deterministic and realized WinForms checks cover model/queue combinations, keyboard and programmatic heading rejection, remembered values, active/paused changes, Analysis configuration, compact/default fit, and prior gate/forward-only behavior. Full x86/x64 totals and release hashes are retained in the private checkpoint.

## Known limitations

- Forward-only admission still supports only **Drop newest** and **Drop incoming complete notes**. Other finite overflow policies require simulated delayed processing because already-sent MIDI cannot be removed.
