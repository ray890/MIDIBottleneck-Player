# Build 24

**Version:** v1.0.24

**Original handoff date:** 2026-09-21 7:20 AM EDT

## Player changes

- Added a deterministic per-note interval gate, available from the title-bar system menu.
- Applied one independent interval to each MIDI pitch across all channels, with stable boundary ordering and an initial first-NoteOn/channel ownership rule.
- Counted note events rejected by the gate separately from queue-overflow drops.
- Used the established silence/restart boundary for live mode and interval changes so stale ownership cannot leave notes stuck.
- Clearly labelled static Analysis as excluding this first live-only gate model.

## Repository, documentation, and distribution changes

- Corrected Build 23 documentation to separate its player fix from publication and packaging work.
- Documented why local deterministic testing remains authoritative until UI-independent and realized WinForms tests can be separated for hosted CI.
- Removed the ineffective x86 configuration sidecar while retaining the required x64 very-large-array configuration.
- Updated architecture-specific packages: x86 contains the executable, README, and license; x64 additionally contains its required `.exe.config`.

## Verification

Focused gate, lifecycle, UI, Analysis-disclosure, and package checks passed before the complete deterministic x86/x64 suites and release smoke tests. Exact totals and artifact hashes are recorded in the private Build 24 checkpoint and the published checksum manifest.

## Known limitations

- Static Analysis does not simulate the per-note interval gate; it says so explicitly and continues to project the ordinary immutable source/configuration queue model.
- The initial ownership rule can suppress valid repeated attacks when a longer note on another track or channel already holds the same pitch. Build 25 replaces this interpretation while retaining Build 24 here as an honest historical record.
- The x64 executable still requires its adjacent `.exe.config` while the current event store may allocate a contiguous reference array larger than 2 GB.

## Historical note

Build 24 moves forward from the published Build 23 commit and tag. No earlier public commit or tag was rewritten.
