# Build 26

**Version:** v1.0.26

**Original handoff date:** 2026-09-22 5:12 AM EDT

## Player changes

- Replaced the Per-note interval gate's fixed 16,384-entry occurrence pool with reusable 4,096-entry segments that grow with the number of simultaneously unmatched source notes.
- Removed lossy overflow bookkeeping that could let one track's NoteOff prematurely retire another track's valid same-channel/same-pitch occurrence.
- Preserved selected support from another enabled channel when a live channel-disable operation silences the currently sounding representative.
- Added a workload-only initial Analysis preview after event, byte, cluster, and message-type scanning completes.
- Added explicit pending, cancelled, and unavailable projection states without displaying unfinished queue values as zero.
- Kept completed Analysis graphs visible during recalculation and independently rejected stale preview and final generations.

## Repository and documentation changes

- Updated the user guide, technical reference, limitations, roadmap, and engineering opportunities for the hardened gate and completed preview milestone.
- Added deterministic coverage beyond the former pool ceiling and for asynchronous preview publication, cancellation, cache reuse, detachment, and stale-result rejection.

## Verification

Focused gate and Analysis-preview tests passed before the final release gate. The complete deterministic suite passed 93/93 on x86 and 93/93 on x64, and both exact packaged executables passed bounded launch/normal-close smoke tests. Package hashes are published in `SHA256SUMS.txt`.

## Known limitations

- Static Analysis still excludes the live Per-note interval gate; the preview represents immutable source workload, not a gate projection.
- Occurrence memory follows peak simultaneous unmatched-note overlap. A genuine segment-allocation failure is reported and stops playback rather than degrading pairing correctness.
- Compact segmented event storage and whole-state Play/Seek chase remain separate future projects.
