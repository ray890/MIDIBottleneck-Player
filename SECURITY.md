# Security policy

## Supported version

Security fixes target the latest published MIDIBottleneck Player release. Older historical tags document prior milestones but are not maintained separately.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private-reporting feature for this repository. Do not disclose an exploitable driver crash, unsafe native-call boundary, credential exposure, or similar issue in a public issue before it can be triaged.

Include the application build, Windows architecture, selected output API, a bounded reproduction, and whether any test input can legally be shared. Do not upload proprietary MIDI files, provider binaries, memory dumps containing personal data, or credentials.

Ordinary playback bugs and deterministic simulator discrepancies may use the public issue templates.
