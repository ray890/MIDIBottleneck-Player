# Public-history provenance

The Build 01–22 history is reconstructed because the project did not originally have Git commits. Commit subjects, parents, repository identity, and dates are archival metadata based on completed handoffs.

The public history preserves the best surviving source, tests, build scripts, and project documentation at each milestone. Private recovery snapshots were compared first. A milestone is labelled **exact** only when a complete handoff tree is supported by retained evidence; **nearest preserved** means an exact handoff tree does not survive and no missing source lines were invented.

The publication rewrite deliberately omits the private diagnostics archive from every public commit. That archive included raw native-provider logs, personal machine paths, and publication-irrelevant compatibility material. Private recovery refs remain local and are not part of ordinary `main` or version-tag pushes.

Historical dates in commits and release-note headings are original handoff dates. GitHub's web page shows the later date on which a Release entry was actually published; that platform date is not presented as the original handoff date.
