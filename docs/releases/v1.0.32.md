# Build 32

Original handoff date: 2026-09-23 12:20 PM EDT

## Player changes

- Added checked-by-default MIDI-state restoration when Play or Seek begins after the start of a file.
- Restores bank, Program, ordinary controllers, pitch bend, channel pressure, and known RPN/NRPN parameter values before later notes.
- Respects disabled channels and forced Channel Monitor overrides.
- Keeps Pause silent and restores reset controller state once when Resume continues.

## MIDI-state behavior

- Bank selection precedes Program; parameter selectors and Data Entry remain ordered.
- Events exactly at the target remain normal source events and are not duplicated.
- Notes, polyphonic key pressure, SysEx, system/meta messages, and channel-mode silence commands are never chased.
- An increment/decrement of an unknown parameter value is omitted rather than guessed.

## Verification

- Focused lifecycle, ordering, reset, override, disabled-channel, segment-boundary, cancellation, and failure tests were added.
- Complete x86/x64 totals and release hashes are recorded in the private Build 32 checkpoint.

## Known limitations

- Direct Events/sec input remains deferred; Processing time per event remains the equivalent existing rate control.
- Static Per-note Analysis, Drop oldest complete note, and presentation scaling remain separate future work.
