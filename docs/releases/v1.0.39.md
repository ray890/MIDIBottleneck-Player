# Build 39 — Numeric controls and Per-note Analysis

Original handoff date: 2026-09-25 EDT

## Player changes

- The main numeric fields now center their values and fit the digits shown. Queue-limit dragging is gentler at small values and accelerates at larger ones; holding Shift makes fine adjustments.
- Analysis now shows an exact source-file projection of the shared Per-note interval gate. Its graph compares the original MIDI workload with the gate's selected messages at their logical send times. The report gives projected message and filter totals without presenting ordinary queue-overflow results as gate behavior.

## Project and documentation changes

- Updated the user and technical guides to distinguish static gate decisions from live driver timing and channel filters. Runtime UI scaling remains deferred.

## Verification

- Focused deterministic tests compare projected MIDI payloads and order with live fake-output playback, cover compact/reference event stores, workload-cache reuse, cancellation, and the workload-only preview. Complete x86/x64 test totals and exact executable hashes are retained in the private release checkpoint.

## Known limitations

- Static Analysis does not include live Channel Monitor mutes or forced overrides, native-driver delays, synthesizer rendering, or audible release tails.
