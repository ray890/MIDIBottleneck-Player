# Build 33 — Direct event rate

Original handoff date: 2026-09-23 EDT

## Player changes

- Added **Events per second** as a direct service-rate choice alongside Processing time and MIDI bitrate.
- Kept fractional timing exactly with an integer remainder, including rates that do not divide evenly into one second.
- Made delayed playback, forward-only queue admission, and Analysis use the same admission and service-phase rules.
- Made live rate and model edits use the established safe same-position restart boundary.

## Verification

- Deterministic tests cover exact rates, zero/immediate service, queue limits, rejected events, conversions, responsive layout, active-playback restart, and state-chase ordering.
- Final architecture and package totals are recorded in the private Build 33 checkpoint.

## Known limitations

- Events/sec models the player’s selected service capacity. It does not predict a MIDI driver’s or synthesizer’s internal throughput.
