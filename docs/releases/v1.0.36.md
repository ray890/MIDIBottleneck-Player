# Build 36 — Session view controls

Original handoff date: 2026-09-24 EDT

## Player changes

- Added checked-by-default **Show Processing model** and **Show Statistics** commands to the main window's Windows title-bar menu. Hide either section, or both, to make the window shorter. File/output and Playback remain visible.
- Hiding a section changes only what is shown. Rate and queue settings, playback, output, and statistics continue unchanged. When Statistics returns, it shows current values.
- The window remeasures its compact height or standard minimum after each choice. Restoring both sections brings back the established layout. Choices last only for the current session.

## Verification

- Deterministic x86 and x64 tests cover menu checks, measured layouts, breakpoint crossings, loading, paused and playing use, and restoration. Existing finite-queue and complete-note overflow tests remain part of the release gate.

## Known limitations

- Hiding a section does not disable its processing model. Other presentation modes, such as app-relative UI scaling or roll-up, remain separate future work.
