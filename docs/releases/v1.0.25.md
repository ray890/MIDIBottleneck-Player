## Player changes

- Replaced the Per-note interval gate's first-channel ownership rule with distinct source-note occurrences and a global Up/Down output constraint for each pitch.
- Preserved valid repeated attacks over longer overlapping notes by inserting a clean one-interval release gap before each retrigger.
- Coalesced truly simultaneous same-pitch layers using the strongest velocity and deterministic source order.
- Guaranteed a complete interval for short and zero-duration notes.
- Added bounded one-boundary look-ahead so genuine overload is thinned across a dense run without an unbounded transition queue.
- Kept gate filtering separate from queue overflow and retained safe Pause, Seek, Stop, output-restart, and channel-disable boundaries.

## Repository and documentation changes

- Audited the tracked Build 01–24 release descriptions for readable player, repository, verification, and provenance distinctions before synchronizing the live Releases.
