# Build 27

Original handoff date: 2026-09-22 7:55 AM EDT

## Player changes

- Replaced the final per-event object/reference store with immutable 40-byte records in bounded segments.
- Stored variable-length SysEx and system payloads byte-exactly in a segmented side store.
- Migrated playback, seeking, Analysis, channel state, one-value chase, diagnostics, SysEx assembly, and the per-note gate to allocation-free compact event views.
- Kept a valid workload-only Analysis preview visible when queue projection fails and now shows the concise failure reason.

## Storage and measured memory

- Record segments hold 65,536 events (2.5 MiB when full); payload segments hold 1 MiB.
- On the bounded one-million-short-event x64 fixture, retained managed memory fell from about 81.3 MB to 41.3 MB and private memory from about 77.3 MB to 48.9 MB.
- Compact conversion took about 65 ms. Analysis took about 20 ms and immediate None playback about 52 ms with no measured Gen0 collections in either phase.

## Verification

- Reference and compact backends were compared for event identity, payload bytes, ordering, lower-bound seeks, queue projection, Analysis, playback, and segment boundaries.
- The complete deterministic suite passed 94/94 on x86 and 94/94 on x64. Both packaged executables launched and closed normally.

## Known limitations

- Parsing still builds legacy per-track objects and a contiguous merged list before cancellable conversion. Direct construction into compact segments is the next storage stage.
- The x64 configuration sidecar remains required for that legacy parse/merge path.
- Static Analysis still excludes the live per-note interval gate and live Channel Monitor filtering.
