# Build 34 — Uninterrupted rate edits and Channels readouts

Original handoff date: 2026-09-23 EDT

## Player changes

- Changing Processing time, MIDI bitrate, or Events/sec during playback now takes effect as the next event starts service. The current sound, pending queue, and playback statistics continue without a restart.
- Channels can show source-file values from before the selected position in gray italics when no output value has been confirmed. Forced values still take precedence; looking at Channels sends no MIDI.
- The window menu now starts with **Apply queue limit without slowdown** unchecked and places MIDI-state chase above Always on top.

## Verification

- The complete deterministic suite passed 101/101 on x86 and 101/101 on x64. Focused tests covered live queues and virtual pressure, rapid rate edits, source-history ordering, monitor appearance, and output continuity.

## Known limitations

- Source-derived gray values describe the file before the current position. They do not prove that the MIDI output received that value.
