# Build 37 — Interface refinements

Original handoff date: 2026-09-24 EDT

## Player changes

- Clarified Per-note gate-filter counts and compact statistics spacing. The Analysis graph now shortens long statistic values before captions, with full values available on hover.
- Pressing Space while the active Analysis graph is under the pointer now uses the normal Play/Pause/Resume command. Text editing and modal dialogs retain their own keyboard behavior.
- Opening Channels with MIDI-state chase enabled now requests an ordered chase; only values confirmed sent appear as current observations. Source-only values remain visibly historical, and reopening an already-visible monitor does not send them twice.
- Replaced the Processing value and Queue limit spinners with numeric click-to-type and horizontal-scrub fields. The Events/sec slider is finer at low rates, and exact typed values can reach 9,999,999/sec.
- Placed **Always on top** beside the two session view commands in the title-bar menu.

## Queue performance

- Repeated bounded measurements found the older finite queue policies slower after the Build 35 queue migration. A reusable segmented FIFO recovered much of that local Analysis overhead without changing projected drops or occupancy. It does not imply the same speedup for a real MIDI provider.

## Verification

- Focused control, Analysis, Channels, high-rate, finite-queue, and lifecycle checks passed on both architectures. The complete deterministic suite and exact release hashes are recorded in the release checkpoint.

## Known limitations

- Static Analysis still does not simulate the live Per-note interval gate. Native provider latency and synthesizer rendering remain outside its projection.
- App-relative UI scaling remains a separate future design; this build keeps the established 100% default and compact geometry.
